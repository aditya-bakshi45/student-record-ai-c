# Student Record and Result Management System (C)

Console-based, menu-driven project for **Programming in C (PRC1001)**, B.Tech CSE, Semester I, UPES.
It stores student records, calculates CGPA, and gives simple CGPA-based academic advice.

## Features
- Add / search / delete / display student records (5 sample students are pre-loaded)
- Fields: SAP ID, Roll No., Name, Phone, Email, Year, Semesters completed, SGPA for 8 semesters
- CGPA of each student (average of available SGPA values)
- Year-wise average CGPA
- Display sorted by SAP ID and by Name
- **AI-Assisted Academic Advisor** (if-else logic on CGPA)
- Input validation (SAP ID, 10-digit phone, email, SGPA 0-10, duplicate SAP ID)

## Academic Advisor categories
| CGPA | Category |
| --- | --- |
| >= 8.5 | Excellent Performance |
| 7.0 - 8.49 | Good Performance |
| 5.0 - 6.99 | Needs Improvement |
| < 5.0 | Requires Immediate Attention |

The advice text is generated by the C program (`getAdvice()`); no AI API is used.

## How to compile and run
```bash
gcc -Wall -o student SAP_ID.c
./student
# or run with the sample input:
./student < tests/sample_input.txt
```

## Notes
- "Semesters completed" = number of semesters whose SGPA is available. CGPA = sum of those SGPAs / that number.
- Records are kept in memory (array of structs); data is not saved after exit.
